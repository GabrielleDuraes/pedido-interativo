# 💚 Pedido Interativo

Projeto web desenvolvido como prática inicial de HTML, CSS e JavaScript.

A proposta foi criar uma página interativa com uma sequência de perguntas, botões com comportamentos diferentes e uma animação final.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## ✨ Funcionalidades

- Sequência de perguntas controlada por JavaScript
- Manipulação dinâmica de textos
- Botão "NÃO" com movimento aleatório
- Compatibilidade com mouse e toque
- Animação de corações
- Layout responsivo para computador e celular
- Publicação online com GitHub Pages

## 🧠 O que aprendi

Durante o desenvolvimento pratiquei conceitos como:

- Estrutura básica de uma página HTML
- Estilização com CSS
- Variáveis em JavaScript
- Condicionais if e else if
- Eventos de click, mouseover e touchstart
- Criação e utilização de funções
- Manipulação do DOM
- Uso de id
- Debugging
- Publicação de um projeto com GitHub Pages
